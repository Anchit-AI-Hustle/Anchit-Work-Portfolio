How they are made

No engine

Plain JavaScript and canvas

Every road, pitch, crowd and car is drawn in code at runtime. There are no image files, sprite sheets or game engines behind them, so each game loads in a moment.

One shell

Shared controls and screens

All of them sit on one small shell that handles the keyboard, the mouse, the on-screen stick and buttons, pausing, sound and saved scores, so a game only has to be a game. The legend on the pause screen matches the device you brought.

Original

Familiar genres, new worlds

The genres are ones I grew up playing. The cities, teams, tracks and rules of the lane are my own inventions.
