Shared sign-in

One script tag. Google sign-in on every project.

No database, no monthly plan, nothing that can pause. Google does not charge for sign-in.

Not signed in.

Add it to any project

<script src="https://anchit-tandon.com/assets/anchit-auth.js"
        data-client-id="YOUR_GOOGLE_CLIENT_ID"></script>
<div data-anchit-signin></div>

Then read the user anywhere:

AnchitAuth.onChange(user => {
  if (user) console.log(user.email, user.name);
});

await AnchitAuth.require();   // resolves once signed in

One-time setup, free

  1. console.cloud.google.com → APIs & Services → Credentials
  2. Create OAuth client ID → Web application
  3. Add every origin that will sign people in under Authorised JavaScript origins
  4. Set GOOGLE_CLIENT_ID in the Vercel project, and pass the same value as data-client-id

The client ID is public by design. There is no client secret in this flow, and no password is ever created or stored.
